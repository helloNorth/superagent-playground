# superagent-playground

[简体中文](README.md) | [English](README.en.md)

用于验证 [`dsh-superagent`](https://github.com/deepseek-ai/deepseek-harness)
端到端流程的演练仓库。

## 项目简介

本仓库不包含业务代码，而是一个**稳定、低风险**的验证目标：用于跑通
`dsh-superagent` 的完整链路——从接收人工提出的请求，到产出经过评审的变更，
从而端到端验证这条链路本身是否正常。

因此这里的改动会刻意做得小而清晰：重点在于流程，而不在于内容。

## 用途

- 验证在聊天工具（例如飞书）中提出的请求能被接收、规划并执行。
- 验证变更以 Pull Request 的形式交付，并包含评审与 CI 检查。
- 验证问题与结果能回到提出请求的人所在的原始会话中。
- 提供一个可复现、可调试的问题验证场所，不必改动生产仓库。

## 贡献指南

1. 为你的改动新建一个分支。
2. 每个 Pull Request 只做一件小而聚焦的事。
3. 向默认分支提交 Pull Request，并说明改了什么、如何验证。
4. 如果修改了其中一个语言版本，请同时更新另一个版本。
